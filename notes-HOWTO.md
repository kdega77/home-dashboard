# How to add notes to the entrance dashboard (from your phone)

The dashboard shows whatever is written in **notes.txt** — one note per
line. Edit that file and the wall updates within ~15 minutes (or right
away if you reload the dashboard in Fully Kiosk).

## In the GitHub app

1. Open the **GitHub app** and go to the repo **kdega77/home-dashboard**
   (Home tab → your repositories, or search for it).
2. In the repo's file list, tap **notes.txt**.
3. Tap the **pencil icon** (top right) to edit. If you don't see it, tap
   the **⋯** menu and choose **Edit file**.
4. Type your notes — **one note per line**, for example:
   ```
   Milk and bread from Costco
   Garbage day tomorrow
   ```
   To remove a note, delete its line. Empty file = no Notes card.
5. Tap **✓** (top right), leave the commit message as-is (or write
   "Notes"), and tap **Commit changes**.

## If the app won't let you edit

Use the phone browser instead: go to **github.com/kdega77/home-dashboard**,
tap **notes.txt**, tap the pencil icon, edit, and tap **Commit changes**.

## Or the lazy way

Just tell Muse in chat ("add X to the notes" / "clear the notes")
and it publishes the same file for you.
